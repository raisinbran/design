Portfolio Studio 2.0 - Apple Silicon source launcher

Requirements: macOS 13+, native arm64/universal2 Python 3.11+ (3.13 recommended)
from python.org with its bundled Tcl/Tk, plus this complete portfolio checkout.
The Mac can use M-series Apple Silicon; photo inference runs on CPU, not CUDA.
https://www.python.org/downloads/macos/
https://www.python.org/download/mac/tcltk/

Setup
1. Copy/clone the portfolio repository to the Mac. Do not copy the Windows .venv.
2. In tools/portfolio-studio, run LAUNCH_PORTFOLIO_STUDIO_MAC.command. If the
   checkout did not retain its executable bit, run this once from Terminal:
     chmod +x LAUNCH_PORTFOLIO_STUDIO_MAC.command
   Or extract the provided macOS-launchers.zip INTO tools/portfolio-studio; the
   archive records executable permissions for the launcher and app entry point.
3. The launcher creates .venv-macos, installs dependencies, downloads/verifies
   the small offline description model once, and starts Studio. Subsequent image
   analysis is local. First setup requires Internet access for dependencies.
4. The Portfolio Studio.app launcher in that same folder opens the command file
   in Terminal. Keep it with the checkout; it is not a standalone packaged app.
   The bundle is unsigned/unnotarized. Follow normal macOS app-opening controls;
   do not disable Gatekeeper or other system protections.

Platform changes
- Published files open using macOS open rather than Windows os.startfile.
- Remove from repository uses Send2Trash and macOS Trash, without unlink fallback.
- Notification previews use built-in macOS sounds and the selected volume.
- Settings/private records: ~/Library/Application Support/PortfolioStudio.
- Model and project-preview cache: ~/Library/Caches/PortfolioStudio.
- Ctrl-click supports clearing a crop; unsupported resize cursors fall back safely.
- Window maximize restoration falls back to a screen-fitting window when needed.

Validation limits
Developed on Windows. Windows regression tests, platform-adapter tests, dependency
wheel checks, launcher syntax and bundle permission checks can be performed here.
Actual macOS Tk rendering, Finder/Trash integration, sounds and app launching still
need a smoke test on an Apple Silicon Mac. This is not a notarized release and
has not been represented as hardware-tested.
