Engineering workspace — Portfolio Studio 2.0

Restart Studio using the normal launcher, then select Engineering next to Photography.
The seven existing projects are imported without changing their page markup.

Select a thumbnail to edit project text, visibility, initial expansion, or cover focus.
Project media supports images (including HEIC), MP4/WebM video, and PDF documents.
Add, reorder, caption, credit, and preview media; choose an image as the section cover.
External images are resized to a maximum 1800 pixels; originals are preserved.

New and duplicated projects begin as drafts. Preview page includes the selected draft;
enable Show on Engineering page when ready, then Save changes locally.
Saving updates data/engineering-catalog.json and engineeringdesign.html together,
with a private backup and rollback on failure. Concurrent file changes require Reload.
Removed projects/media retain their files. Nothing is committed or pushed by saving.

Engineering and Photography share the app and master Settings/About controls.
Archive editing remains future work; the Engineering editor does not edit Archive.
For Apple Silicon setup and validation limits, see MACOS_SETUP.txt.
