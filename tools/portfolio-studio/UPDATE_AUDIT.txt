ABSENT OR INCOMPLETE; REPAIRED IN THIS LOCAL UPDATE
- Stage 6O: management tree now belongs to its actual display pane; first row
  is selected and previewed. Empty results clear the previous preview.
- Stage 6O: logo inspection uses an alpha histogram, removing deprecated getdata.
- Manual nonempty description edits check Reviewed in both editors. Loading
  preserves status; generated suggestions remain unreviewed; manual unchecking
  remains possible. Published review state uses the existing altNeedsReview flag.
- Corner signature now samples luminance/detail under its mask and adapts tone
  and opacity; text and grape silhouette share a grayscale treatment. Tiled
  watermark behavior is unchanged. Existing JPEGs are not re-exported.
- Editing groups overflow based on measured width and restore automatically;
  overflow menus operate on the same values. Main inspect and other settings
  share one compact row. Fixed size-based hiding was removed.
- Main More actions uses one arrow on a standard button. Hidden menu actions
  inherit the current enabled/disabled states, including Reset actions.
- Rotation undo is tracked per photo and supports manually entered rotation;
  undo disables after use. Tag/review edits update Reset button states.
- Visiting unchanged originals no longer incorrectly enables Reset all.
- Published editor cached-photo loading no longer references an uninitialized path.
- Published Apply gallery crop disables after applying/loading/resetting.
- Crop handle hit testing chooses the nearest edge for small rectangles and
  accepts the handle hit area just outside the photograph. Resize cursors added.
- Extreme inward ratio resizing keeps both dimensions above minimum size.
- Main measurement readouts account for rotation crop dimensions; source sizes
  are cached instead of reopening/decoding the original on every crop movement.

VALIDATION
Run from repository root with the existing Studio environment:
  tools\portfolio-studio\.venv\Scripts\python.exe -m unittest discover -s tools/portfolio-studio -p test_studio.py -v

Regression suite checks export/source protection, dark/light watermark contrast,
tiled watermark isolation, actual rotation dimensions, manual/generated review,
reset state, cached-photo loading, management list/preview, measured toolbar

Tests use hidden Windows Tk windows and temporary synthetic source images.
No test saves the real catalog, deletes published photos, or uploads images.

No commit or push performed. Website pages, catalog data, original photos and
existing published JPEGs were not changed by this update. Restart Studio using
the existing launcher to load the updated Python files. No installer is needed.

Interactive visual review of the new toolbar layouts is still recommended;
